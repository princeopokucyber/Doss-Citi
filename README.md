Dompoase Stays Central

Welcome to Doss City Guest House, located in Dompoase, Ashanti Region, Ghana.

This website showcases our guest house, rooms, amenities, and services, helping visitors discover a comfortable place to stay.

Features

- Responsive design for mobile and desktop
- Guest house photo gallery and image carousel
- Room and accommodation information
- Booking enquiry and availability interface
- Guest house contact and location details

Built With

- React
- TypeScript
- Tailwind CSS
